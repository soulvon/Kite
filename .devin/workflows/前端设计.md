# 前端设计助手

当用户使用 `/前端设计` 命令时，执行以下步骤：

## 激活指令

1. 阅读 skill 文档以获取完整能力：
   ```
   view_file: .agent/skills/frontend-designer/SKILL.md
   ```

2. 根据用户需求，选择性阅读参考文档：
   - **组件库架构**: `.agent/skills/frontend-designer/references/component_library.md`
   - **设计令牌**: `.agent/skills/frontend-designer/references/design_tokens.md`
   - **可访问性清单**: `.agent/skills/frontend-designer/references/accessibility_checklist.md`
   - **响应式模式**: `.agent/skills/frontend-designer/references/responsive_patterns.md`

## 核心能力

| 能力     | 说明                                       |
| -------- | ------------------------------------------ |
| 组件设计 | 原子设计方法、可重用组件、Props 定制       |
| 设计系统 | 颜色、间距、字体、阴影等设计令牌           |
| 可访问性 | WCAG 2.1 AA 合规、键盘导航、屏幕阅读器支持 |
| 响应式   | 移动优先、流式布局、容器查询               |
| 性能优化 | 懒加载、关键 CSS、Tree Shaking             |

## 使用场景

- "帮我设计一个按钮组件"
- "创建一个响应式卡片布局"
- "检查这个组件的可访问性"
- "生成设计系统的颜色令牌"
- "优化这个页面的性能"
