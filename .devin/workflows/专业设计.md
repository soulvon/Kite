# 专业设计 Workflow

## 触发条件
用户输入 `/专业设计` 或提出涉及视觉/交互式前端产出的需求。

## 执行步骤

### 1. 加载技能
// turbo
读取技能文件获取完整指令：
```
view_file .agent/skills/web-design-engineer/SKILL.md
```

### 2. 理解需求（Step 1）
根据用户提供的信息量决定是否提问：
- 信息充足 → 直接开始
- 信息模糊 → 围绕产品背景、输出类型、变体维度、约束条件进行提问
- **不要机械地列一堆问题，按需精准提问**

### 3. 收集设计上下文（Step 2）
按优先级收集参考资料：
1. 用户主动提供的资源（截图/代码/设计系统）
2. 用户产品的现有页面
3. 行业最佳实践
4. 从零开始（需告知用户影响）

**代码 ≫ 截图**：有代码就读代码提取 token，别猜截图。

### 4. 声明设计系统（Step 3）
写代码前先用 Markdown 声明设计决策，让用户确认：
- 色彩方案、字体搭配、间距系统、圆角策略、阴影层次、动效风格

### 5. 快速展示 v0 草稿（Step 4）
用占位符 + 核心布局 + 设计系统先出一个"可看的 v0"，让用户提前纠偏。

### 6. 完整构建（Step 5）
v0 确认后，写完整组件、添加状态、实现动效。遵循技能文件中的技术规范和设计原则。

### 7. 交付验证（Step 6）
逐项检查交付清单：
- [ ] 浏览器控制台无报错
- [ ] 目标设备/视口正确渲染
- [ ] 交互组件包含完整状态
- [ ] 无文字溢出/截断
- [ ] 颜色全部来自设计系统
- [ ] 无 AI 设计陈词滥调
- [ ] 无填充内容/虚假数据
- [ ] 视觉品质达到 Dribbble/Behance 展示级别
