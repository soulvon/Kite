# 🔍 系统化调试

> 随机修复浪费时间还会引入新 bug。先找根因，再修复。

## 🚀 激活指令

请立即加载并执行 [systematic-debugging 技能](file:///e:/project/GenStudio/.agent/skills/systematic-debugging/SKILL.md) 中的四阶段调试流程：

1. **阶段一：根因调查** — 读错误信息、复现、检查变更、追踪数据流
2. **阶段二：模式分析** — 找工作样例、对比差异
3. **阶段三：假设验证** — 科学方法，最小变更
4. **阶段四：实现修复** — 先写失败测试，单一修复

## 铁律

```
没有根因调查 → 不提修复方案
连续失败 3 次 → 质疑架构
```

## 使用场景

- "这个 bug 不知道怎么回事"
- "测试失败了，帮我排查"
- "修了好几次还是不行"
