# 🧪 测试驱动开发 (TDD)

> 先写测试，看它失败，再写最少代码让它通过。

## 🚀 激活指令

请立即加载并执行 [test-driven-development 技能](file:///e:/project/GenStudio/.agent/skills/test-driven-development/SKILL.md) 中的完整 TDD 循环：

1. **🔴 红** — 写一个失败的测试
2. **验证失败** — 确认测试因功能缺失而失败
3. **🟢 绿** — 写最少代码让测试通过
4. **验证通过** — 确认所有测试通过
5. **🔵 重构** — 清理代码，保持测试绿色
6. **重复** — 下一个测试

## 铁律

```
没有失败的测试 → 不写生产代码
```

## 使用场景

- "帮我用 TDD 实现新功能"
- "写测试再写代码"
- "这个 bug 先写个测试"
