# 🎨 前端设计（Anthropic 官方）

> Anthropic 官方出品，创造独特的生产级前端界面，拒绝"AI 通用美学"。

## 🚀 激活指令

请立即加载并执行 [frontend-design 技能](file:///e:/project/GenStudio/.agent/skills/frontend-design/SKILL.md) 的设计流程：

1. **设计思考** — 理解上下文，选择大胆的美学方向
2. **排版** — 独特有性格的字体搭配
3. **配色主题** — CSS 变量一致性，主色+锐利点缀色
4. **动效** — 高影响力的入场动画和微交互
5. **空间构图** — 非对称/打破网格/负空间
6. **视觉细节** — 纹理/渐变/阴影/装饰

## 禁止事项

❌ 通用字体（Inter, Roboto, Arial）
❌ 陈词滥调配色（紫色渐变白底）
❌ 套路化的布局和组件
