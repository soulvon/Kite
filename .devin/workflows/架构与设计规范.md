# 架构与设计规范

通用 UI 组件和代码架构规范，确保代码复用和一致性。

## 3. 主题系统

- 核心文件: `constants/theme.ts`, `types/index.ts`, `stores/uiStore.ts`
- 2 套预设主题 (亮色 Light / 暗色 Dark)

```tsx
// ✅ 正确
const theme = useUIStore(state => state.currentTheme);
<div className={`${theme.bg} ${theme.text}`}>...</div>

// ❌ 错误：硬编码颜色
<div className="bg-zinc-900 text-white">...</div>
```

## 4. 媒体文件路径

| 上下文                | 格式                         |
| --------------------- | ---------------------------- |
| 渲染进程 (HTML/Video) | `media://local?path=...`     |
| 主进程/存储           | 本地路径 `C:/Users/test.mp4` |

> [!IMPORTANT]
> **Asset.src 统一存储本地路径**，渲染进程显示时再转换为 `media://` 格式。

```typescript
// 主进程工具: electron/utils/mediaPathResolver.ts
toLocalPath('media://local?path=C%3A%2Ftest.mp4')  // => 'C:/test.mp4'
toMediaUrl('C:/test.mp4')  // => 'media://local?path=...'
```

## 5. 基础 UI 组件

| 组件                                                         | 说明                           |
| ------------------------------------------------------------ | ------------------------------ |
| `Button`                                                     | primary/secondary/ghost/danger |

## 6. 图标系统

- **一律使用 SVG 图标，禁止使用 Emoji**
- 统一使用 `lucide-react`，stroke-width: 2
- 尺寸: `w-4 h-4` (16px) / `w-5 h-5` (20px) / `w-6 h-6` (24px)

```tsx
// ✅ 正确
<Save className={`w-4 h-4 ${theme.accent}`} />
// ❌ 错误
<Save style={{ width: 16 }} />
```

## 7. IPC 通信规范

**命名格式**: `模块:动作` (如 `ffmpeg:probe-file`, `fs:read-file`)

**渲染进程调用方式**: `window.electron.invoke('xxx:action', options)`

```typescript
// electron/ipc/handlers/xxxHandlers.ts
export function registerXxxHandlers() {
  ipcMain.handle('xxx:action', async (event, options) => { /* ... */ });
}
```

## 8. 日志系统

> [!CAUTION]
> **禁止使用 console.log**，调试信息统一写入 `UserDatas/Logs/`。
> 使用 `UserDataPaths.getLogsDir()` 获取日志目录。

```typescript
// 主进程
import { DebugLogger } from '../utils/DebugLogger';
const logger = new DebugLogger('scene-detection');
logger.log('开始检测', { filePath: '...' });

// 渲染进程
import { logOperation } from '@/utils/OperationLogger';
logOperation('selection', 'box-select', { clipIds: [...] });
```

## 10. 用户配置持久化

- **Electron**: SQLite | **Web**: localStorage/IndexedDB
- 所有键名定义在 `utils/storage/types.ts` 的 `SETTING_KEYS`

**双写策略**:
1. 读取: 优先 storageService，fallback localStorage
2. 写入: 同步写 localStorage，异步写 storageService

## 11. 目录配置规范

> [!IMPORTANT]
> **禁止使用 `app.getPath('userData')`**，必须使用 `UserDataPaths`。

| 用途     | 方法                              |
| -------- | --------------------------------- |
| 根目录   | `UserDataPaths.getUserDatasDir()` |
| 项目目录 | `UserDataPaths.getProjectsDir()`  |
| 数据库   | `UserDataPaths.getDbPath()`       |

```
UserDatas/
├── genstudio.db        # SQLite 数据库
├── projects/           # 项目文件 (可自定义)
├── cache/              # 缓存 (thumbnails/, waveforms/)
├── temp/               # 临时文件
└── config/             # 配置文件
```

## 12. 资源目录规范 (resources/)

> [!IMPORTANT]
> **第三方工具和模型统一放在 `resources/extensions/` 目录**

### 12.1 目录结构 (新)

```
resources/
└── extensions/                        # 统一拓展目录
    ├── extension-registry.json        # 可用拓展清单
    │
    ├── ffmpeg/                        # 媒体工具
    │   ├── manifest.json
    │   ├── ffmpeg.exe
    │   └── ffprobe.exe
    │
    ├── whisper/                       # AI 工具 (带变体)
    │   ├── manifest.json
    │   ├── cpu/
    │   │   └── whisper-cli.exe
    │   ├── cuda/
    │   │   └── whisper-cli.exe
    │   └── models/                    # 模型作为子资源
    │       └── ggml-base.bin
    │
    ├── comfyui/                       # 本地 API 服务
    │   ├── manifest.json
    │   ├── main.py
    │   └── venv/
    │
    ├── python/                        # 运行环境
    │   ├── manifest.json
    │   └── python.exe
    │
    └── chromium/                      # 运行环境
        ├── manifest.json
        └── chrome-win/
```

### 12.2 分类规则

| 类型          | 放置目录           | manifest.category | 示例                     |
| ------------- | ------------------ | ----------------- | ------------------------ |
| 媒体工具      | `extensions/<id>/` | `media-tools`     | ffmpeg, yt-dlp           |
| AI 工具       | `extensions/<id>/` | `ai-tools`        | whisper, iopaint         |
| 本地 API 服务 | `extensions/<id>/` | `api-service`     | comfyui, jimeng-free-api |
| 运行环境      | `extensions/<id>/` | `runtime`         | python, chromium         |

> **模型不再单独存放**，作为工具的子资源存放在 `extensions/<tool-id>/models/`

### 12.3 manifest.json 规范

每个拓展目录必须包含 `manifest.json`：

```json
{
  "id": "whisper",
  "name": "Whisper.cpp",
  "displayName": "Whisper 语音识别",
  "version": "1.7.5",
  "category": "ai-tools",
  "description": "本地语音识别引擎",
  
  "variants": [
    { "id": "cpu", "executable": "cpu/whisper-cli.exe" },
    { "id": "cuda", "executable": "cuda/whisper-cli.exe", "recommended": true }
  ],
  
  "models": [
    { "id": "base", "file": "models/ggml-base.bin", "size": "142 MB" }
  ],
  
  "capabilities": [
    { "id": "whisper-stt", "name": "语音转文字", "action": "analyze" }
  ]
}
```

> 详见 `spec/23_拓展中心(EXTENSION_HUB).md`

### 12.4 PathManager 使用 (更新)

```typescript
import { getPathManager } from '../utils/PathManager';
const paths = getPathManager();

// 获取拓展目录
paths.getExtensionPath('whisper')           // → resources/extensions/whisper/
paths.getExtensionExecutable('whisper')     // → resources/extensions/whisper/cpu/whisper-cli.exe

// 获取模型 (作为拓展子资源)
paths.getExtensionModelPath('whisper', 'ggml-base.bin')  
// → resources/extensions/whisper/models/ggml-base.bin

// ⨂ 废弃的 API (保留别名兼容)
paths.getToolDir('whisper')                 // → 转发到 getExtensionPath
paths.getModelDir('whisper')                // → 转发到 getExtensionModelPath
```
