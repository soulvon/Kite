## 📋 推荐工作流

### 快速审查（最常用）
```
/无瑕设计 审查
```
→ 输出 5 维度评分报告 + 修复建议

### 完整优化流程
```
/无瑕设计 审查    → 了解问题
/无瑕设计 规范化  → 对齐设计系统
/无瑕设计 配色    → 优化色彩
/无瑕设计 排版    → 优化字体
/无瑕设计 打磨    → 最终打磨
/无瑕设计 审查    → 确认改善
```

### 视觉风格调整
```
/无瑕设计 加粗    → 设计太保守？放大冲击力
/无瑕设计 柔和    → 设计太刺激？降低强度
/无瑕设计 配色    → 太单色？增添色彩
/无瑕设计 极致    → 想要 WOW 效果？上极致
```

## 使用场景

- 开发了新页面："帮我用 `/无瑕设计 审查` 看看有没有 AI 味"
- 觉得界面太普通："`/无瑕设计 加粗`"
- 发布前最终检查："`/无瑕设计 打磨`"
- 想要动画效果："`/无瑕设计 动效`"
- 整体优化："`/无瑕设计`"（加载核心设计技能）
