# 语言特征提取 (Linguistic Feature Extraction)

本技能旨在通过对用户回复数据的深度分析，构建一个高保真的“语言特征画像 (Linguistic Profile)”，以便在后续交互或文案生成中实现精准的风格模仿。

## 核心流程

### 1. 数据收集 (Data Sourcing)
- 调取用户最近的 10-20 条有效回复（去除纯指令型短语）。
- 识别用户在不同情绪状态（如：提问、报错、点赞、闲聊）下的表达差异。

### 2. 特征分析 (Feature Analysis)
依照 `resources/profile_schema.json` 中的维度进行扫描：
- **词法特征**：识别独有词汇和口头禅（如：习惯叫“兄弟”还是“老师”）。
- **语法特征**：分析句长分布（满篇短句还是逻辑严密的复合长句）。
- **标点与符号**：捕捉独特的标点组合（如：习惯用波浪号 ~ 还是多个冒号）。
- **情绪感官**：评估语言的能量值（Energy Level）和正式度（Formality）。

### 3. 画像记录 (Profile Logging)
- 按照 `resources/profile_schema.json` 格式生成结构化数据。
- 确保导出内容包含 3 个以上的“模仿关键点 (Imitation Hooks)”。

## 使用指南

### 当用户要求“模仿我”时：
1. **启动分析**：主动告知用户你将分析其过往对话。
2. **提取特征**：依据 Schema 提取特征。
3. **确认反馈**：向用户展示提取出的“核心口头禅”和“语感倾向”，询问是否准确。
4. **注入上下文**：将该画像缓存为后续生成的样式指南。

## 资源参考

- **特征格式规范**：[profile_schema.json](resources/profile_schema.json) - 包含 7 大维度、20+ 细分指标的精细化记录格式。

## 注意事项

- **拒绝过度模仿**：如果用户本身语言极度口语化，在处理严谨代码逻辑时应适当克制，保留其语气词但保证逻辑清晰。
- **动态更新**：语言特征随项目阶段可能变化，建议每隔一段时间（或用户风格明显波动时）重新校准。
