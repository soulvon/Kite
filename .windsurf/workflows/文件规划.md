# 📋 文件规划工作流

> 像 Manus 一样工作：用磁盘上的 Markdown 文件作为"工作记忆"。

## 🚀 激活指令

请立即加载并执行 [planning-with-files 技能](file:///e:/project/GenStudio/.agent/skills/planning-with-files/SKILL.md) 的完整流程：

1. **检查已有规划文件** — 如存在 `task_plan.md` 则恢复上下文
2. **创建 `task_plan.md`** — 分阶段记录任务
3. **创建 `findings.md`** — 存储研究发现
4. **创建 `progress.md`** — 会话日志和测试结果
5. **每阶段完成后更新** — 标记进度，记录错误

## 核心原则

| 原则       | 说明                   |
| ---------- | ---------------------- |
| 先建计划   | 复杂任务不建计划不开工 |
| 2 步法则   | 每 2 次操作后保存发现  |
| 读后再决策 | 重大决策前重新读计划   |
| 做完就更新 | 完成阶段立即更新状态   |

## 使用场景

- "这个任务很复杂，帮我规划"
- "分步骤帮我做"
- "需要多步调研"
