# 🧪 自测

> 开发完成后，根据会话上下文智能生成并执行测试

## 🚀 激活指令

请立即加载并执行 [self-testing 技能](file:///e:/project/GenStudio/.agent/skills/self-testing/SKILL.md) 中的完整流程：

1. **上下文分析** — 回顾本次会话改了什么
2. **生成测试计划** — 列出测试点，分类为单元/E2E
3. **用户确认** — 展示计划，等待确认
4. **执行单元测试** — Vitest 运行，结果收集
5. **执行 E2E 测试** — CDP 连接 Electron，DOM 断言 + 截图
6. **测试报告** — 汇总通过/失败，附截图和修复建议

## 使用场景

- 开发完一个功能后："帮我测一下"
- 修完 Bug 后："/自测"
- 重构后验证："/自测 重点看看 XX 功能"
