BYOK 使用说明
什么是 BYOK？
BYOK（Bring Your Own Key）让你使用自己的 API Key 驱动 Windsurf，绕开官方配额限制。

使用步骤
1 在「API 供应商」中填入你的 API 密钥
2 启用需要的供应商开关
3 点击「测试全部连接」验证密钥
4 点击「应用全部补丁」注入代理
5 重启 Windsurf 即可使用自己的 Key

支持协议
OpenAI 兼容 Anthropic Google Gemini
